# Unfog mobile app

Expo SDK 57 app for Android and iOS. Setup, configuration and testing are in the root `README.md`. The device test plan is `docs/QA_TEST_PLAN.md`.

```bash
cp .env.example .env          # set EXPO_PUBLIC_API_URL to your API
npx expo run:android          # build and install the development app
npm start                     # JavaScript server for an installed development app
npm run typecheck && npm run lint
```

Expo Go cannot run this app. It needs a development build because of background location and MapLibre.

## Layout

| Path | Contents |
|---|---|
| `index.ts` | Entry. Registers the background location task before the router loads. |
| `src/app` | Screens (expo-router). `(tabs)` holds Map, Memory, Crew, Card and Me. |
| `src/lib` | API client, auth state, local SQLite store, tracking, upload queue, privacy zones. |
| `src/components` | Shared UI, the story card, the rewards banner. |
| `app.config.ts` | App name, IDs, permissions and plugins, driven by environment variables. |
| `eas.json` | Cloud build profiles: development, preview and production. |

`android/` and `ios/` are generated by `expo prebuild` and are not committed. Change native settings in `app.config.ts`, never by hand.
